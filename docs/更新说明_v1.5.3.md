# 宇宙银河机甲 UrhoX 版 v1.5.3：去掉敌弹沿途闪烁的亮点

对应网页版《宇宙银河机甲_测试版_25.html》（网页版画面不变）。

## 闪烁亮点从哪来
敌人每颗子弹飞行时，每帧有 50% 概率在身后丢一个“拖尾粒子”；拖尾粒子是白热渐变（刚出现时接近白色，随后变红、变暗），再加上 v1.5.0 起每个粒子都带一圈柔光，于是敌弹沿途不停随机冒出白色亮点，看起来一闪一闪。我方激光也有同样的拖尾（70% 概率）。另外敌人开火时枪口会冒 3 个火花，也是一闪。

## 改动
- 战斗模块给这些粒子标上来源：敌弹拖尾、我方激光拖尾、敌人枪口火花（只是标记，网页版画面不变）。
- UrhoX：敌弹拖尾、我方激光拖尾不画；敌人枪口火花亮度降到 0.3、不加柔光；敌人蓄力环 / 砸地环的光点亮度降到 0.45、不加柔光。
- 导弹尾焰、爆炸余烬等其他粒子保持不变。

- Lua 与预览规则逐项一致（新增枪口火花、敌人环点 3 个用例，共 14 项）。
- 渲染后端（柔光 / 退回两条路径）、界面流程、无尽、每日挑战、第 1 章远征无报错；同一随机种子下战斗结果与 v1.5.2 完全相同（只改了标记，玩法没变）。
