# 宇宙银河机甲 UrhoX 版 v1.5.0：攻击特效改用柔光贴片

只改 UrhoX 渲染（`scripts/jsrt/Renderer.lua`）并新增贴图 `assets/Textures/fx_glow.png`；战斗逻辑与 v1.4.9 / 网页版 24 相同。

## 为什么 v1.4.9 还是奇怪
v1.4.9 的光套是放大的半透明方块，叠几层也还是方方正正的硬边，在真机上像一根根发光的方棍。网页版的柔光来自 HDR 辉光（把亮部模糊开），UrhoX 的辉光是 LDR 硬阈值，模糊不开彩色特效。

## 改成什么
- 柔光改用 UrhoX 的 BillboardSet（广告牌）+ 径向渐变贴图 + 叠加混合，每个贴片自带颜色和亮度，边缘真正柔和：
  - 圆形柔光（始终面向镜头）：火花、余烬、小方块，随寿命淡出；推进器白芯一层很淡的柔光。
  - 细长柔光（沿弹道方向拉长）：机甲子弹 / 激光、敌人子弹，宽度为弹道粗细的 7 / 8.5 倍，长度为弹道的 1.3 倍。
- 弹道本体横向变细到 0.75 倍，让柔光成为主体；敌人子弹本体亮度降到 0.65，红色柔光为主，白芯不再刺眼。
- 每帧最多 400 个圆形 + 400 个细长柔光，各一次绘制调用，比方块光套更省。

## 怎么验证的
- 预览页（`tools/fx_preview/`）新增了柔光贴片模拟，网页版 / v1.4.9 / v1.5.0 三方对比见 `docs/特效对比/对比_v1.5.0_柔光贴片.jpg`。
- Lua 规则与预览规则逐项对照：11 种典型特效的本体亮度、本体缩放、柔光类型 / 尺寸 / 颜色完全一致。
- 渲染后端无头测试（贴片路径与退回路径都跑了）、界面流程、无尽、每日挑战、第 1 章远征全部无报错。

## 自动退回
找不到贴图、找不到叠加顶点色技术（DiffVColAdd / DiffVColAddAlpha）、或贴片更新出错时，自动退回 v1.4.9 的方块光套，不会黑屏或报错。

## 真机上请留意
- 本机没有 UrhoX 引擎，BillboardSet 的接口按 Urho3D 标准写法：如果真机上柔光大小是预期的两倍或一半，改 `Renderer.lua` 里的 `SPR_HALF`（0.5 -> 1 或 0.25）。
- 柔光太亮 / 太淡：改 `fxRuleSpr` 里 `addS(...)` 的亮度（细长柔光 1.0 / 0.8，圆形 0.55）。
- 新增贴图需要随包打进资源（`.project` 是全量引用，正常会自动包含）。
