# 宇宙银河机甲 UrhoX 版 v1.4.8：特效亮度分档（推进器尾焰变柔）

只改 `scripts/jsrt/Renderer.lua`（和版本号）。

## 问题
v1.4.6 起发光特效改为叠加混合，亮度一律 0.95。机甲推进器尾焰每个喷口由 5 块发光方块组成，几个喷口叠在画面正中，叠加后接近纯白，再加上外层光晕和辉光，显得刺眼。

## 修改（按绘制类型分档）
| 特效 | 叠加亮度 | 光晕 |
|---|---|---|
| 推进器尾焰（白芯） | 0.45 | 无 |
| 推进器尾焰（机甲颜色段） | 0.32 | 无 |
| 大块闪光（枪口闪光、起爆闪光等，尺寸 > 6） | 0.7 | 无 |
| 其他特效（火花、弹芯、子弹、激光、余烬） | 0.9 | 白芯 / 火花有，仅尺寸 <= 4 的小块 |

- 辉光强度系数 0.82 -> 0.78，整体再收一点。
- 网页版战斗逻辑不变（绘制列表里已有 kind：0 场景 / 推进器，1 敌人攻击，2 特效）。

## 测试
渲染后端无头测试（第 3 章）：尾焰走 0.32 / 0.45 两档、大闪光 0.7、其他 0.9，无报错。

## 还可以手动微调（Renderer.lua 的 addK）
- 尾焰仍偏亮：把 0.32 / 0.45 再调低（如 0.25 / 0.35）。
- 开枪闪光太亮：把 0.7 调低。
- 整体偏暗：把 0.9 调到 1.0，或在设置里把“辉光”调到“强”。
