# UrhoX 版与网页版（宇宙银河机甲.html）一致性对照（v1.1.0，v1.3.6 补充见末尾）

**结论：玩法与数据由网页版源码自动转换，战斗逻辑经逐帧对照一致；差异只在界面版式与少数展示效果。**

## 一致（有证据）
| 项目 | 验证方式 | 结果 |
|---|---|---|
| 1080 张卡牌的名称与词条、每日挑战、研发费用、等级倍率、芯片属性汇总（含金色特性） | 网页版与 Lua 版各自计算后逐项比对 | 全部一致 |
| 6 台机甲 x 3 章节的战斗（含技能、氮气、升级选择、元素反应、新敌人、盾卫格挡） | 固定随机种子 + 同一段操作，各跑 900 帧，比对位置 / 耐久 / 击破 / 等级 / 经验 / 每个敌人血量与位置 | 完全一致 |
| 首领战（第 1、3 章）、无尽模式 + 危险等级、每日挑战（含词缀） | 同上，各 1200 帧 | 完全一致 |
| 伤害数字、锁定框、预警、屏幕外箭头、摇杆圈等 2D 叠加层 | 网页版 drawOverlay 经转换后，通过 Canvas->NanoVG 适配层绘制 | 逻辑一致（字体与像素细节待真机确认） |

对照过程中发现并修复的转换问题：逻辑运算符求值、对象键枚举顺序（影响升级选项的随机结果）、undefined / 布尔值参与算术、字符串下标取字符、toFixed 负零、多个顶层 IIFE、模型半径缺失。

## 有差异（显示层）
| 项目 | 网页版 | UrhoX 版 |
|---|---|---|
| 机库 / HUD / 弹窗 | HTML + CSS | NanoVG 重画，版式不同，按钮逻辑一致 |
| 召唤动画 | DOM + 3D | 3D 部分（蓄力、坠落、爆发、粒子）与网页版一致；闪光、翻牌、展示页用 NanoVG 重画 |
| 存档导出 / 导入 | 文本框 | 未提供 |
| 机库 3D 场景 | 完整装饰 + 拖动旋转 | 装饰与机位已移植，自转，无拖动旋转 |
| 广告 | 模拟 | TapTap 激励视频（容器内），不可用时不发奖励 |

## 未验证
未在真实 UrhoX / TapTap 制造中运行；见 docs/UrhoX移植说明.md 第五节。

## v1.4.2 补充
