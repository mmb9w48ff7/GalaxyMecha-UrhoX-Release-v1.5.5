# 宇宙银河机甲 UrhoX 版 v1.4.3 修复说明

只改 UrhoX 版手写的界面 / 渲染代码，战斗逻辑（CosmicRun.lua / CosmicData.lua）与 v1.4.2、网页版 21 相同。

## 一、点升级卡牌后被弹回机库（v1.4.2 引入）
- 现象：重播新手引导后第一次升级（以及任何时候点卡牌、点“跳过”），界面直接回到机库。
- 原因：`GameUI.lua` 的升级弹窗在点卡牌后会立刻关闭弹窗（`u.levelup = nil`），但同一帧后面新加的“稍后选择”按钮还在读 `u.levelup.forced`，Lua 报错；`main.lua` 的保护逻辑捕获错误后保存存档并返回机库。
- 修复：弹窗开头记下当前状态；点卡牌 / 跳过后本帧直接结束绘制；看广告刷新的回调也先判断弹窗是否还在。

## 二、敌人和机甲的攻击特效显示成白色
- 原因 1（一开始就白）：弹道、激光、火花等特效模型的材质是“受光 + 自发光（颜色 x 1.6~3.5）”。网页版在 HDR 里算完再做色调映射，颜色还在；UrhoX 输出是 LDR，三个通道都被截到 1，青色 / 红色全成了白色。
  修复：`VoxelBuilder.Build` 对 `fx_` 开头、带自发光的模型改用“不受光 + 最大通道为 1”的发光材质，保留色相，亮部仍会触发辉光。
- 原因 2（玩一会儿才白）：`Renderer.lua` 给每种“模型 + 颜色”建一个原型，同一模型超过 120 种颜色后就退回无色模型；尾焰、爆炸余烬的颜色是渐变的，`fx_white` 很快超过上限，之后新出现的特效全是白色。
  修复：特效颜色先按最大通道归一再量化（变体数大约减半）；上限提高到 160，超过后借用最接近的已有颜色，不再退回白色。

## 三、测试（Lua 5.4 无头，引擎 / NanoVG 接口用空实现）
- 界面流程：老存档（“稍后选择”）重播新手引导 -> 第一次升级强制弹出并点卡牌 -> HUD“升级”按钮打开弹窗 -> 暂停 -> 设置 -> 改伤害数字 -> 返回 -> 继续 -> 拾取宝箱 -> 结算页，全程无报错（v1.4.2 在第一次点卡牌时报错）。
- 渲染后端：第 3 章、危险 3 跑完整章，特效模型全部走发光材质；`fx_white` 颜色变体 75 个，没有任何退回无色模型的情况。
- 所有 Lua 文件编译通过。
