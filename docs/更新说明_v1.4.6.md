# 宇宙银河机甲 UrhoX 版 v1.4.6：特效柔和化

对应网页版《宇宙银河机甲_测试版_23.html》。

## 为什么生硬
UrhoX 里的弹道、火花、激光、尾焰都是不透明的发光方块：颜色一块一块、边缘是硬直角，互相遮挡；网页版靠 HDR 辉光把它们晕开，UrhoX 的辉光是硬阈值，晕不开。

## 改了什么
- 特效本体改为叠加混合（`Renderer.lua`）：白芯、火花、敌我弹道、激光像光一样叠加在画面上，不再是实心方块互相遮挡；重叠处自然变亮。宝石（经验）和碎石仍是实体。
- 光晕更柔：外层光晕放大到 2.2 倍、亮度降到 0.2，并绕 (1,1,1) 轴转 45 度，与本体叠在一起时轮廓接近圆形，过渡更平滑；每帧最多 110 个。
- 辉光：阈值再降一点、强度 x0.82（原 x0.72）。
- 地点标签（星门 / 求救信号等）落在顶部标题或右上角连击数的区域时变淡（35%），不再压住连击数字（战斗逻辑改动，网页版同步）。
- 绘制列表带上 `kind`（场景 / 敌人 / 特效），供渲染器区分；网页版画面不变。
- 叠加与光晕的颜色变体都经过同一套上限（每个模型 160 种），超出借用最接近的颜色。

引擎里找不到叠加混合技术（NoTextureAdd / NoTextureUnlitAdd / DiffAdd）时，自动退回 v1.4.5 的不透明发光材质，不会黑屏。设置里“辉光”选“弱”时关闭光晕（叠加本体仍生效）。

## 测试（Lua 5.4 无头，引擎接口空实现）
- 渲染后端跑第 3 章：叠加本体原型 83 个、光晕原型 61 个，没有任何退回无色模型。
- 界面流程（重播引导、选卡、HUD 升级按钮、暂停设置、宝箱、结算）、无尽、每日挑战、第 1 章远征全部无报错，战斗数据与 v1.4.5 一致。
- 网页版 23 跑 250 秒无脚本错误。

## 真机请看
- 特效是否变柔和、是否偏淡：偏淡可把 `Renderer.lua` 里 `addProto` 的 `halo = 0.95` 调到 1.0，光晕 `HALO_K = 0.2` 调到 0.25。
- 太亮或掉帧：设置里“辉光”选“弱”（关闭光晕）；若想完全回到旧效果，把 `Renderer.lua` 里 `ADD_IDS` 清空。
