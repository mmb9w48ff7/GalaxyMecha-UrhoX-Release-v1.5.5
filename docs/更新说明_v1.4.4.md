# 宇宙银河机甲 UrhoX 版 v1.4.4：触控优化、画面色彩与特效增强

只改 UrhoX 手写的界面 / 渲染代码（WebUI.lua、Hub.lua、GameApp.lua、VoxelBuilder.lua、Renderer.lua），战斗逻辑不变。

## 一、手机触控（顶栏“返回 / 技能模块·天赋芯片·武器 / + / 设置”难点中）
- 触控吸附：本帧没点中任何按钮的触点（以及按下后几乎没移动就松开的触点），吸附到 44 设计像素内最近的按钮，下一帧触发；精确点中永远优先；战斗中的摇杆 / 视角触点不参与。
- 按钮放大：“+” 44x44 -> 58x58；“设置” 100x66 -> 124x80；“返回” 140x76 -> 156x86；工坊页签高 70 -> 84（点击区 96）。
- 无头测试：点在“设置”右侧 / 下方 24~28 像素外、工坊页签上方 10 像素外、“返回”下方 10 像素外都能触发；远离按钮的空白处不会误触。

## 二、画面色彩
- 饱和度：设置里的“色彩”三档由 1.0 / 1.3 / 1.6 提高到 1.15 / 1.5 / 1.8（默认“鲜艳” = 1.5）。
- 对比度：环境光 x0.85、主光 x1.15，明暗更有层次、不发灰。
- 辉光：阈值略降、强度 x1.2。

## 三、特效
- 特效颜色先按最大通道归一再提饱和度（x1.35）：白芯仍是白色，青色激光、红色子弹、橙色火花更艳。
- 新增光晕：发光特效（弹道、激光、火花）外面叠一层放大 1.9 倍的叠加混合模型，每帧最多 90 个；设置里“辉光”选“弱”时关闭。
  引擎里找不到叠加技术（NoTextureAdd / NoTextureUnlitAdd / DiffAdd）时自动不画光晕，不影响其他画面。

## 四、请在真机确认
- 光晕是否太亮或影响帧率：太亮可把 Renderer.lua 里 `halo = 0.32` 调小；帧率不够可把 `HALO_MAX = 90` 调小，或在设置里把“辉光”设为“弱”。
- 饱和度如果过艳，设置里“色彩”选“标准”（1.15）。
