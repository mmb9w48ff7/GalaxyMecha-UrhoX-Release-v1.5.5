# 宇宙银河机甲 UrhoX 版 v1.4.2 更新说明：新手体验、设置与玩法

对应网页版《宇宙银河机甲_测试版_21.html》。战斗逻辑改在网页版 `cosmic_run.js` / `cosmic_data.js`，用 `tools/xpile_lite` 转换出 `CosmicRun.lua` / `CosmicData.lua`（源码在 `tools/xpile_lite/src_web21/`）。手写界面改了 `GameUI.lua` 与 `Hub.lua`。

## 一、新手第一局
- 第一星域固定为“海贼据点”（规则最直观），进场怪群减半、星门充能数量 x0.6；前两个星域不出游荡精英；第一星域只有一扇星门。
- 第一次升级必定弹出选卡窗口（不受“稍后选择”设置影响），副标题讲解：新技能 / 技能升级 / 机甲强化，Lv5 后可进化。
- 新手引导改为 6 步，按设备显示文字（手机：摇杆与按钮；电脑：WASD / 空格 / Shift），已完成的步骤自动跳过；引导框移到顶部目标栏下方，不再挡住机甲；弹窗打开时隐藏。
- 手机第 1 步在左下角显示闪烁的虚线摇杆“按住拖动飞行”。
- 引导逻辑统一在战斗模块（`startTutorial`，状态 `R.tutUI`），`GameUI.lua` 只负责显示，网页版与 UrhoX 版不再各写一份。

## 二、升级选卡
- 默认改为“立即弹出”。老存档：打过 3 局以上、没改过这项设置的，保持原来的“稍后选择”。
- 弹窗里“稍后选择”不再是高亮主按钮；新手第一次与宝箱升级时不显示“稍后”。

## 三、新玩法
- **星门二选一**（第 1~4 星域，新手第一星域除外）：青色「稳航」跃迁时修复 60%（平时 30%）；红色「险途」下个星域敌人血量 x1.2、伤害 x1.1、多 1 只游荡精英，星门开启时必掉宝箱。屏幕外箭头会同时标出两扇门，门上写着各自效果。
- **宝箱升级加倍**：拾取宝箱时短暂慢动作，随即弹出“宝箱奖励！”选卡；选中的技能 / 强化额外 +1 级（新技能直接 Lv2；进化 / 回复 / 弹药改为额外修复 30%）。
- **连击狂热**：30 / 60 / 100 连击时主武器射速 +20% / +35% / +50%，持续 6 秒；连击数字旁显示“狂热”。
- **结算页显示本局构筑**（技能名、等级、是否进化）。

## 四、设置
- 暂停菜单新增“设置”：战斗中可改 升级选卡 / 伤害数字 / 闲置时镜头转向目标 / 视角灵敏度 / 战斗视角 / 副武器自动发射 / 背景音乐 / 音效，立即生效并存档（设置项表 `BATTLE_SET` 在战斗模块，两端共用）。
- 机库设置新增：伤害数字、闲置时镜头转向目标、视角灵敏度（低 / 中 / 高）。网页版设置分为 战斗 / 画面 / 声音 / 其他 四组。

## 五、界面
- 出击按钮“约 6 分钟”改为“约 4 分钟”（实测一章 2.5~3 分钟，真人约 4~5 分钟）。
- 工坊“已收集 x / 1080 张卡牌”改为“图鉴 x / 120 种（形态 x 元素）　卡牌 n 张”。
- 机库“推荐下一步”最多 2 条；网页版修正 16:9 下与底部导航的重叠，手机横屏（界面缩放 < 0.5）时放大次要说明文字。

## 六、测试
- 网页版（无头浏览器）：全新存档走完新手局（首个星域为海贼据点、第一次升级强制弹出、引导 1 -> 6）、暂停设置、两扇星门、险途进入下个星域、宝箱加倍、结算构筑，均无脚本错误。
- 不躲弹、关无敌的机器人平均阵亡星域：19 版 5.0，20 版 5.3，21 版 5.5（默认走稳航，修复更多；险途更难）。
- Lua 版（Lua 5.4 无头，装上 `GameUI` 的逻辑部分）：新存档默认“立即弹出”、新手局强制选卡与引导推进、险途 / 稳航跃迁修复（30% / 60%）与险途宝箱、宝箱加倍、连击狂热、战斗设置读写、结算构筑；第 1~3 章、无尽、每日挑战、危险等级 5 全部无报错。

## 七、需要在真机确认
- `GameUI.lua`：顶部新手引导框、暂停菜单三个按钮、“战斗设置”面板（8 行）、升级弹窗副标题长度。
- `Hub.lua`：设置面板改为 11 行（高度 90~1030），请确认不与关闭按钮重叠。
- 手机上的字号：网页版已对小屏放大说明文字；UrhoX 版界面按 1920x1080 绘制，若真机上说明文字太小，可统一调大 `Hub.lua` 中 18~22 号字。
