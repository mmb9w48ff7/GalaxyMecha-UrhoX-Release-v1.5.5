# 宇宙银河机甲 UrhoX 版 v1.5.5：修复激光两侧的“竖条”与机甲变粉

只改 `scripts/jsrt/Renderer.lua`（和版本号）。

## 问题 1：激光 / 子弹两侧出现一排排粉色、青色竖条
v1.5.0 起细长柔光用的是 UrhoX 广告牌的“沿方向”模式（FC_DIRECTION）。这个模式在 TapTap 制造的 UrhoX 里朝向和标准 Urho3D 不一致：柔光没有沿着激光，而是横在激光上，长条变成垂直于激光的竖条；首领激光、狙击线由很多小段组成，于是变成一整排竖条。预览页模拟的是标准行为，所以之前没发现。

修复：不再使用“沿方向”广告牌。子弹 / 激光改为“细本体（横向 0.8 倍）+ 一层贴身光套（横向 1.7 倍、长度 1.04 倍，亮度 敌 0.1 / 我 0.08，预警细线减半）”。光套是跟模型一起摆放的方块，方向由弹道自身的矩阵决定，一定和弹道对齐。圆形柔光（火花、余烬、闪光，“面向镜头”模式是粒子的默认模式）保留。

## 问题 2：机甲被打中时整台变成粉色
受击时战斗代码给机甲部件加了红色“颜色替换”。网页版只是一闪；UrhoX 里颜色替换会把整台机甲的所有颜色换成粉红，显得像出错。现在 UrhoX 不给机甲部件做受击染色，受击反馈保留屏幕边缘红闪、震屏和音效。

- 渲染后端（柔光 / 退回两条路径）、界面流程、无尽测试无报错。
