# 宇宙银河机甲 v1.4.5：无尽模式割草化

对应网页版《宇宙银河机甲_测试版_22.html》。只改战斗模块 `cosmic_run.js`（无尽 / 每日挑战的刷怪），由转换器重新生成 `CosmicRun.lua`；界面与渲染与 v1.4.4 相同。

## 改了什么（只影响无尽模式和每日挑战，远征不变）
- 刷怪速率：1.1 + 0.18 x 波数 -> 3 + 0.45 x 波数（只 / 秒），并改为 3~6 只一群出现（原来一只一只）。
- 怪潮：每波第 1.5 秒和第 25 秒，在玩家四周 30~40 米围一圈爬虫（第 2 波起混入自爆虫，第 3 波起部分换成裂变晶体），数量 12 + 3 x 波数 / 8 + 2 x 波数。怪潮敌人血量 x0.7、接触伤害 x0.6、45% 掉经验、信用点 x0.5。
- 同屏上限：38 + 6 x 波数（最多 150）-> 50 + 7 x 波数（最多 110），怪潮另算，场上总数不超过 140；低帧率时按画质系数自动减少。
- 收益：无尽结算的击破奖励每只 3 -> 1、普通敌人信用点 x0.6，避免信用点暴涨。
