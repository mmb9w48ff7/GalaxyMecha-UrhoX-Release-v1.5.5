# 宇宙银河机甲 UrhoX 版 v1.3.6 更新说明

本版按《宇宙银河机甲_测试版_18.html》同步卡牌系统，并修复 UrhoX 版“背景星空”和“进入星门效果”不显示的问题。

## 一、卡牌系统（与 18 版网页一致）

- **不再装备卡牌**：拥有的卡牌全部进入卡组（同一 形态 + 元素 只取最强的一张：品质优先，其次等级）。
- **局内随机组合**：出击时卡组洗牌，开局随机带 1 张；每次升级最多随机给 2 张新卡（技能少于 3 个时新卡更容易出），每局最多 6 个技能。
- **抽卡**：信用点抽 1 次 / 抽 10 次（10 连 9 折，必出蓝色以上）；抽完可“看广告 翻倍”，免费再抽同样次数。
- **战力**：按卡组里最强的 3 张计算。
- **升级刷新**：每局免费 2 次，之后看广告最多再刷新 3 次。
  - 18 版网页按钮显示“还可 3 次”，但代码在第 2 次后就拦住了；这里统一为 3 次。如需改回 2 次，改 `scripts/cosmic/GameUI.lua` 顶部的 `AD_REFRESH`。
- 机库：工坊技能模块页去掉装备槽与装备按钮，改为“本局卡组 N 张”说明；新增抽 1 次 / 抽 10 次按钮与抽卡结果弹窗（10 连两行展示，最新抽到的格子标“新”）；“推荐下一步”、战力提示、关于与合规页的概率公示同步网页文案。
- 旧存档兼容：旧的 `modEq`（装备列表）保留但不再使用，已拥有的卡牌自动进入卡组。

改动文件：`scripts/jsrt/CosmicData.lua`、`scripts/jsrt/CosmicRun.lua`（按转换器输出的写法手工同步）、`scripts/cosmic/Hub.lua`、`scripts/cosmic/GameUI.lua`。

## 二、背景星空不显示（已修复）

- 原因：星点在离镜头 3000～3600 米的球壳上；战斗场景的雾在 420 米处已全浓。网页版着色器在算雾之前就输出星点，所以不受雾影响；UrhoX 的不受光材质照样被雾盖住，星点被染成背景色，看起来就是一片黑。召唤页的星空同样受影响。
- 修复：新增一个“星空专用无雾区域”（Zone）。主区域掩码 = 1，星空区域掩码 = 2、优先级更低；星点几何体掩码 = 2，只受星空区域影响，其他物体仍用原来的雾。
- 另外：星点亮度按网页版取 0.9（gamma，对应网页版线性 x0.8），低于辉光阈值，转动镜头不会闪；回到机库首页时隐藏星空；战斗 / 召唤页的星空各建一次并缓存，不再来回重建。

改动文件：`scripts/cosmic/GameApp.lua`、`scripts/jsrt/Renderer.lua`、`scripts/game/VoxelBuilder.lua`。

## 三、进入星门效果不显示（已修复）

- 原因：网页版的跃迁效果是网页层 `#warp`：中心青色、往外深蓝到近黑的椭圆渐变，0.28 秒淡入，停 0.6 秒切换星域后淡出。转换后的战斗代码用 `document.getElementById('warp')` 取这个元素，UrhoX 里拿到的是空占位，所以什么都不画（暂停、切换星域、音效本身都正常）。
- 同样原因，受击时屏幕边缘的粉红闪光（`#hitflash`）也没有显示，一并修复。
- 修复：`GameApp.lua` 给 `warp` / `hitflash` 返回能记录 `classList` / `style.opacity` 的元素；`GameUI.lua` 按网页版 CSS 的过渡时间（0.28 秒 / 0.12 秒，ease 曲线）用 NanoVG 径向渐变画出来，层级在 3D 标记之上、HUD 之下，与网页版一致。转换来的战斗代码不用改。

## 四、测试（模拟引擎）

- 数据层与网页版对照：同一确定性随机数下，10 连价格、抽 1 / 10 次 / 看广告翻倍的结果、卡组、最强 3 张、战力、信用点不足提示，网页版与 Lua 版逐项一致。
- 冒烟测试：机库各页面、抽卡与翻倍按钮点击、局内卡组（开局 1 张、每次升级最多 2 张新卡、满 6 个后不再出新卡）、升级弹窗免费刷新 2 次、受击闪光、进入星门遮罩（淡入、0.6 秒后进入下一星域、淡出）、星空区域与显示 / 隐藏，全部通过。
- 3 章 x 2 种升级模式连续战斗约 2 万帧，无报错。

## 五、需要在真机 / TapTap 制造里确认

1. 星空：战斗中背景应能看到白 / 青 / 橙三色星点；召唤页也有星空。若仍看不到，请告诉我，我改用备用方案（星点不走雾的自定义材质）。
2. 飞进星门：屏幕先变暗（中心青色），约 0.9 秒后在新星域淡出。
3. 被敌人打中：屏幕边缘短暂粉红。

## 六、以后再从网页版同步时

本包的 `CosmicData.lua` / `CosmicRun.lua` 是按 18 版网页手工同步的。如果用源码工程的转换器（`tools/build_xpile.py`）重新生成，请先把源码工程 `preview/src/` 里的对应 JS 换成 18 版（压缩包里的“网页版18源码_供转换器”文件夹已按模块拆好），否则会被旧版覆盖回去。界面层（Hub.lua / GameUI.lua / GameApp.lua / Renderer.lua）是手写的，不受转换器影响。
