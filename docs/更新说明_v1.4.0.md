# 宇宙银河机甲 UrhoX 版 v1.4.0 更新说明：武器系统

对应网页版《宇宙银河机甲_测试版_19.html》。玩法逻辑在网页版 JS 里写好后，用新的转换器（tools/xpile_lite）自动生成 Lua，两边一致。

## 一、配装：每台机甲 3 个装备栏
- **主武器**：决定弹道。6 个系列（射线枪 / 散射炮 / 追踪光弹 / 双臂机炮 / 肩载导弹 / 晶体长枪）x 3 种型号 = 18 把。第 1 种型号是各机甲原装武器，默认拥有；另外 12 把改型在工坊研发。任何机甲都能装任何主武器，装在“本命”机甲上伤害 +10%。
- **副武器**：飞弹，消耗弹药。6 种：蜂群飞弹、冰霜飞弹、电磁飞弹、集束炸弹、穿甲重弹、引力飞弹。战斗中点“副武器”按钮发射（电脑 Q 键），设置里可开“自动发射”（敌群密集或出现精英 / 首领时才发射，默认开）。
- **氮气推进**：原来 6 台机甲各自的氮气（冲刺 / 冲撞 / 漂移 / 加速 / 后撤 / 跃迁）变成可换的模块，默认全部拥有。
- **机甲技能**：仍然跟着机甲（机甲的身份），配装页一起显示。

## 五、界面
- 工坊新增“武器”分页：上方是当前机甲的 3 个装备栏（左右箭头切换机甲），下面是主武器 / 副武器 / 氮气列表；右侧详情里研发、装备、升级、看广告升级、合成弹药。
- 机库：机甲详情显示配装与机甲特性，新增“武器配装”按钮直达工坊。
- 战斗：氮气按钮上方新增副武器按钮（名称、弹药、冷却）。结算页显示本局消耗的飞弹。
- 设置：新增“副武器自动发射”开关。推荐下一步：弹药不足 10 发时提醒。
- 战力：只计算超出初始配装的部分（武器升级 / 改型 / 高级飞弹 / 氮气升级），老存档战力不变。

## 六、转换器（tools/xpile_lite）
- `node --expose-internals tools/xpile_lite/transpile.js cosmic_data.js cosmic_icons.js -o scripts/jsrt/CosmicData.lua`
- `node --expose-internals tools/xpile_lite/transpile.js cosmic_run.js -o scripts/jsrt/CosmicRun.lua`
- 验证：用它把 18 版网页源码重新转换，与 v1.3.6 的 Lua 在同一随机种子下逐帧对照（6 台机甲 x 3 章、无尽、每日，共约 5 万帧）完全一致。
- 有 npm 时也可以 `npm i acorn` 后直接 `node transpile.js ...`。

## 七、测试（模拟引擎）
18 把主武器在本命 / 非本命机甲上都能开火造成伤害；6 种飞弹发射、命中、结算扣库存；自动发射、弹药箱、升级补给；氮气模块升级与机甲特性；研发 / 升级 / 合成 / 库存上限；3 章连续战斗与无尽 / 每日模式无报错。网页版 19 在 Chromium 里跑过同样的武器和飞弹，无脚本错误。

## 八、已知限制
- 机甲模型手里的武器外形不会随主武器变化（体素模型固定），变的是弹道、特效和数值。
- 真机上请重点看：副武器按钮的位置和点击、工坊“武器”页的滚动、飞弹特效的数量（低端机如果卡，可以在设置里开省电模式）。
