# 宇宙银河机甲 UrhoX 版 v1.5.1：简洁激光

只改 `scripts/jsrt/Renderer.lua`，新增贴图 `assets/Textures/fx_glow_line.png`。

## 改动
- 去掉激光 / 敌人子弹中间的小光点：激光、敌弹、预警线上附带的小白点（绘制 kind 1 的 fx_white，尺寸 <= 6.5）不再画；激光起点 / 终点的大闪光保留，首领激光蓄力时仍有起点闪光提示。
- 细长柔光换成线形贴图：横向从中心向两侧渐暗，纵向中段均匀、只在两端渐隐。v1.5.0 用的是圆形渐变拉长，中间最亮，看起来像一个光点；现在整条激光亮度一致。
- 线形贴图更“满”，细长柔光亮度相应下调：敌人 1.0 -> 0.7，机甲 0.8 -> 0.6；宽度 8.5 / 7 倍 -> 7 / 6 倍。

## 验证
- 预览页（tools/fx_preview）同步线形衰减与“不画中间光点”规则，对比图 `docs/特效对比/对比_v1.5.1_简洁激光.jpg`。
- Lua 与预览规则逐项一致；渲染后端（柔光路径与退回路径）、界面流程测试无报错。

## 微调
- 激光柔光还嫌宽 / 亮：`fxRuleSpr` 里 `addS(true, ...)` 的宽度 `7 / 6` 与亮度 `0.7 / 0.6`。
- 想把首领激光起点闪光也去掉：把跳过条件里的 `6.5` 改大（如 20）。
