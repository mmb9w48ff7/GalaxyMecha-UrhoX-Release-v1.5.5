# 宇宙银河机甲 UrhoX 版 v1.4.9：攻击特效重做（机甲 / 怪物分开处理）

对应网页版《宇宙银河机甲_测试版_24.html》（网页版画面不变，只是绘制列表多了特效角色信息）。

## 这次怎么调的
之前几版特效都是改完直接给你真机看。这次先做了一个“UrhoX 观感预览”：在网页引擎里模拟 UrhoX 的渲染方式（LDR、gamma 空间、叠加混合、硬阈值辉光），每个方案都截图对比后才定下来，再把规则一字不差地搬进 `Renderer.lua`（无头测试逐条对照，11 种典型特效的亮度、光套层数、尺寸完全一致）。预览工具在 `tools/fx_preview/`，对比图在 `docs/特效对比/`。

## 规则（按特效角色）
战斗模块现在给每个特效标上角色：推进器 / 机甲攻击 / 敌人攻击 / 冲击环 / 粒子 / 经验。

| 角色 | 本体亮度 | 光套 / 光晕 |
|---|---|---|
| 推进器尾焰 | 白芯 0.13，彩色段 0.03~0.10（越往后越淡），本体缩到 0.8 倍 | 无 |
| 机甲攻击：子弹 / 激光 / 射线 | 0.85 | 三层青色（随武器颜色）光套：横向 1.7 / 2.5 / 3.4 倍，长度只加 6~20%，亮度 0.16 / 0.08 / 0.035 |
| 敌人攻击：子弹 | 0.8，白芯改为暖粉色 | 三层红色光套，亮度 0.2 / 0.1 / 0.045，比机甲的更显眼 |
| 敌人预警线（细段） | 0.45 | 两层，亮度减半 |
| 粒子（火花、余烬） | 0.85，随寿命淡出：1 / 0.7 / 0.45 / 0.25 | 小方块两层光晕（1.9 / 2.8 倍），也随寿命淡出 |
| 冲击环 | 0.7，随扩散淡出 | 无 |
| 大块闪光（尺寸 > 6） | 0.6 | 两层（1.5 / 2.1 倍） |

- 光套不再整体放大、不斜转（v1.4.6 的十字形问题），只有小方块光晕会斜转 45 度让轮廓更圆。
- 模型自发光（机甲发光条、敌人眼睛、晶体）：最大通道不超过 0.85，保留颜色，不再发白（`VoxelBuilder.lua`）。
- 每帧光套最多 140 个；叠加原型按“颜色 x 亮度档”共用，每个模型最多 900 个，超出借用最接近的颜色 / 亮度。7 分钟无尽实测只用了 273 个。
- 引擎没有叠加混合技术时自动退回旧材质；设置里“辉光”选“弱”时关闭光套。

## 测试
- 规则对照：Lua 与预览页 11 种典型特效逐项一致。
- 渲染后端：第 3 章、7 分钟无尽均无报错，没有退回普通材质的情况。
- 界面流程、无尽、每日挑战、第 1 章远征全部正常，战斗数据与 v1.4.8 一致。

## 预览的局限
预览只能模拟 UrhoX 的特效混合方式；机甲和敌人本身的受光效果（PBR）与真机仍有差别，所以最终还要以真机为准。真机上想微调：`Renderer.lua` 的 `fxRule`（各角色亮度与光套）。
