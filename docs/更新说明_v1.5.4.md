# 宇宙银河机甲 UrhoX 版 v1.5.4：边缘光辉收小

只改 `scripts/jsrt/Renderer.lua`、`scripts/cosmic/GameUI.lua`（和版本号）。

| 光辉来源 | v1.5.3 | v1.5.4 |
|---|---|---|
| 激光柔光宽度（弹道粗细倍数，敌 / 我） | 4.5 / 4 | 3.5 / 3 |
| 火花 / 余烬圆形柔光 | 5 倍 | 3.5 倍 |
| 大块闪光柔光 | 3 倍 | 2.2 倍 |
| 推进器白芯柔光 | 4.5 倍 | 3 倍 |
| 全屏辉光（Bloom）强度 | 场景值 x0.7（机库可到 0.7） | 场景值 x0.6，封顶 0.5（再乘设置里的“辉光”档位） |
| 受击屏幕边缘红闪 | 从 55% 半径开始，x0.7 | 从 68% 半径开始，x0.5 |

- 机库场景的辉光参数比战斗高（阈值 0.5、强度 1.0），在 UrhoX 里换算后强度约 0.7，机甲白色装甲、青色台座边缘会晕出一大圈；现在封顶 0.5。
- 柔光的亮度不变，只缩小范围；激光、火花的颜色与形状同 v1.5.3。

## 验证
预览对比 `docs/特效对比/对比_v1.5.4_光辉收小.jpg`；Lua 与预览规则逐项一致（14 项）；渲染后端（柔光 / 退回两条路径）、界面流程测试无报错。

## 还嫌大
- 全屏辉光：设置里“辉光”选“弱”（x0.6），或改 `Renderer.lua` 里的封顶值 0.5。
- 某一类特效的柔光：改 `fxRuleSpr` 里对应 `addS(...)` 的倍数。
