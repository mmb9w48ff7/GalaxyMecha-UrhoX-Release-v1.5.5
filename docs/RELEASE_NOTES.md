# 宇宙银河机甲 v1.1.0（UrhoX / TapTap 嵌入式容器）发布说明

## 包内容
- `scripts/`：游戏脚本（入口 `main.lua`）与体素模型数据（仅包含运行所需的 80 余个模型）。
- `assets/Sounds/`：音效与背景音乐（.ogg，共 19 个，路径 `Sounds/xxx.ogg`）。
- `store/`：商店素材——512x512 图标、6 张 1920x1080 截图、宣传片 mp4（1920x1080 / H.264 / 约 30 秒）。
- `docs/`：提审清单、隐私政策与用户协议模板、移植说明。

## 本版（v1.1.0）重点
- 游戏逻辑改为由网页版源码自动转换（不再手写重写），与网页版代码级一致，并有逐帧对照证据；详见 docs/UrhoX移植说明.md。
- 机库、战斗 HUD、弹窗用 NanoVG 重画；召唤动画与存档导出 / 导入暂未提供。
- 旧的手写移植版保存在源码包 legacy/hand_port_v1/ 中，仅供参考。

## 玩法概览
6 台体素 Q 版机甲（S / SS / SSR / SSSR 四档）、6 位驾驶员；3 个章节（每章 6 个星域，含 6 种目标 + 首领）、危险等级 1~10、无尽模式、每日挑战；1080 张技能卡牌 + 天赋芯片 + 元素反应 + 卡牌进化；召唤、每日登录、任务与成就。

## 本版发布处理
- 关闭所有调试开关（无敌 / 调试接口）；每帧逻辑在 pcall 中运行，脚本出错时保存存档并返回机库，不会闪退。
- 去掉模型加载日志；存档读取做了字段补全与兜底，老存档 / 损坏存档不会导致启动失败。
- 广告只走 TapTap 激励视频，SDK 不可用时不弹模拟广告、不发奖励。
- 首次进入显示新手引导；“关于与合规”页含原创声明与抽取概率公示。

## 已知限制（请在提审前确认）
1. 本包只在模拟引擎中完整跑通，**尚未在真正的 UrhoX 编辑器 / 真机上验证**。首次导入后请先试跑并核对 `docs/UrhoX移植说明.md` 的“未验证”清单（旋转方向、枪口位置、触控坐标、性能、SDK 行为）。
2. Lua 版在水平面上飞行，特效比网页版简化。
3. 隐私政策 / 用户协议仅为模板，必须由你补全运营主体并经法务审核。
