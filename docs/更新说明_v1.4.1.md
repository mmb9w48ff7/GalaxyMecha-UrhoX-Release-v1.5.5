# 宇宙银河机甲 UrhoX 版 v1.4.1 更新说明：关卡节奏与战斗密度

对应网页版《宇宙银河机甲_测试版_20.html》。玩法只改了战斗模块 `cosmic_run.js`，用 `tools/xpile_lite` 重新转换出 `scripts/jsrt/CosmicRun.lua`；`CosmicData.lua` 只有第一行注释变化。转换用的网页版 20 源码放在 `tools/xpile_lite/src_web20/`。

## 一、为什么改

用自动驾驶机器人实测 19 版（推荐战力，第 1 章）：
- 整章约 2 分钟，普通星域 12~22 秒，一半以上时间在空飞，同时在场敌人平均只有 3~6 只。
- 精英星域只有 1 只晶核巨兽，7~15 秒打完；首领 11~25 秒。
- 富矿带 / 伏击偶尔卡关拖到 60~100 秒（刷怪速度和敌人血量随停留时间无上限增长；有敌人时自动瞄准从不打矿）。
- 星门开启时把小怪直接清掉，不给经验，飞往星门的路上是空场。

## 二、改动

**刷怪节奏**
- 进场遭遇战：普通 / 商人星域开场就在通往目标的航线上放一群游荡敌人（4 + 2 x 星域 + 3 x (章节 - 1) 只）。
- 成群刷怪：游荡敌人 2~4 只一组出现（同类为主）；基础速率 1.3 + 0.3 x 星域（原 0.9 + 0.22 x 星域）。
- 做目标时游荡刷怪 x0.55，让目标敌人当主角。
- 停留时间带来的增长封顶：刷怪速率最多 +1.2，敌人血量最多 +60%（停留 3 分钟后不再变强）。
- 远征模式游荡敌人同屏上限 60（低帧率时按画质系数下调）。

**星门**
- 星门充能：普通 / 商人星域除了完成目标，还要在本星域击败 (50 + 15 x 星域 + 15 x (章节 - 1)) 个敌人（危险等级每级 +4%），矿石不算。顶部目标栏显示“星门充能：再击败 N 个敌人”，星门标签显示能量百分比；充能期间刷怪 x1.5。
- 星门开启时的冲击波：清除小怪但掉落经验并自动吸附；开门后保留 35% 的刷怪。

**星域目标**
- 海贼据点：10 + 4 x 章节 个海贼，剩 40% 时来一波增援（含 1 个重炮手）。
- 遗弃残骸：搜刮 7 秒，过半时第二波虫群（含自爆虫）。
- 富矿带：激活时出现护矿虫群；矿石比最近的敌人近得多时自动瞄准先打矿。
- 限时猎杀：目标 30 + 10 x 章节。
- 精英伏击：前两波 8 + 2 x 章节，第三波巨兽 + 4 + 章节。
- 同一局普通星域的目标不重复（事件袋）。

**精英与首领**
- 晶簇巢穴（第 3 星域）：3 个晶簇巢（每 5 秒孵出爬虫，第 2 章起混入自爆虫 / 裂变晶体）+ 巨兽守卫（血量 x1.25，半血狂暴：移速 x1.3、砸地冷却 x0.75）。全部摧毁才算完成。
- 游荡精英：第 2 星域起（第 2 章起从第 1 星域开始）每个普通 / 商人星域出现 1 只金色精英（血量 x8，伤害 x1.2），必掉战利品（免费升级 1 次）。
- 首领：每 12 / 10 / 8 秒（按阶段）召唤一队护卫；远征模式首领血量 +35%。

**平衡**
- 远征模式敌人伤害 x0.85；跃迁时修复耐久 20% -> 30%。
- 远征模式单只怪的信用点 x0.6，结算击破奖励每只 3 -> 1。
- 无尽模式与每日挑战的刷怪、伤害、收益不变。

**修复**
- 自爆虫爆炸后血量被置为 0.0001 而没有移除，会每帧重复爆炸、重复计击破 / 经验 / 信用点并反复伤害玩家，直到被子弹补刀。现在爆炸后立即移除（19 版与 UrhoX v1.4.0 都有此问题）。

**界面文字**
- 新手引导增加“击败敌人为星门充能”一步；暂停页说明同步（网页版与 `GameUI.lua`）。
- 星域目标叠加层新增：海贼剩余数量、晶簇巢 x / 3 与守卫状态、星门能量。

## 三、实测（无头浏览器 + 机器人，推荐战力，第 1 章）

| | 19 版 | 20 版 |
|---|---|---|
| 整章用时（开无敌） | 101~160 秒 | 142~170 秒 |
| 击破 | 157~272 | 449~509 |
| 结算信用点 | 2200~3250 | 3260~3440 |
| 本局升级次数 | 9~13 | 17~18 |
| 普通星域交战时间占比 | 25~60% | 多数 60~100% |
| 不躲弹、关无敌的平均阵亡星域 | 5.0（10 局） | 5.3（11 局，1 局通关） |

- Lua 版（Lua 5.4 无头，`jsrt.Host` 装配）：第 1~3 章各 2 局全部通关无报错；无尽 260 秒到第 6 波、首领出现；每日挑战 240 秒正常结算；危险等级 5 整章通关。
- 网页版 20：远征、无尽、每日挑战、危险等级 5 均无脚本错误。

## 四、可调参数（都在 `cosmic_run.js`，改完重新转换）

- 星门充能数量：`loadSector` 里的 `R.gateNeed`。
- 刷怪速率 / 上限：`updateSpawns` 开头的 `cap` 与 `rate`。
- 远征伤害系数：`loadSector` 里 `R.dmgMul` 末尾的 0.85。
- 信用点：`killEnemy` 的 0.6 与 `endRun` 的击破奖励。

## 五、已知限制

- 晶簇巢用的是现有的 `env_crystal_cluster` 模型，游荡精英 / 狂暴守卫用整体色调区分，没有新模型。
- 升级次数接近翻倍，如果设置为“稍后选择”，HUD 上的升级按钮会更常亮。
- 仍需在真机上确认：同屏 50~60 只敌人时的帧率；冲击波、晶簇巢特效。
