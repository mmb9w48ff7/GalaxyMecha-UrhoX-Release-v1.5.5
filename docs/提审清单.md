# TapTap 提审清单（UrhoX 版 v1.0.0）

> 以下为通用清单，具体以 TapTap 开发者后台当前规则为准；版号 / 资质 / 法务事项请向平台客服与专业人士确认。

## 一、先完成（阻塞项）
- [ ] 在 UrhoX 编辑器 / 真机中完整试玩：机库、出击、六台机甲、升级选卡、首领、结算、无尽、每日挑战、工坊、召唤。
- [ ] 核对“未验证”风险：手臂 / 腿转向是否反、枪口是否贴合、触控点击与摇杆坐标、帧率与发热、音频是否出声、广告回调。
- [ ] 真机上测试至少 3 种分辨率 / 比例（含刘海屏），确认 HUD 不被宿主退出按钮遮挡。

## 二、商店资料
- [ ] 应用名称：宇宙银河机甲（提交前在商店与商标局检索是否被占用）。
- [ ] 图标：`store/icon_512.png`（512x512）。
- [ ] 截图：`store/screenshot_1~6.jpg`（建议再用真机截几张替换）。
- [ ] 宣传视频：`store/宇宙银河机甲_宣传片.mp4`（横屏 16:9、1920x1080、H.264、约 30 秒，满足“不少于 15 秒、不低于 1280x720”）；实机视频请另行用真机录制，避免内容高度雷同。
- [ ] 简介 / 标签：体素、Q 版、机甲、割草、肉鸽、单机。
- [ ] 适龄：建议 12+（卡通科幻战斗，无血腥）。

## 三、合规

- [ ] 版号 / 备案：是否需要及办理方式请向 TapTap 确认（本版本无真实货币付费，仅有激励视频广告）。
- [ ] 实名认证与防沉迷：按平台要求接入。
- [ ] 抽取概率公示：已在游戏内“关于与合规”页与召唤页展示，请核对与商店页描述一致。
- [ ] 激励视频广告：只在玩家主动点击时播放，完整观看才发奖励（已按 SDK 文档实现）。
