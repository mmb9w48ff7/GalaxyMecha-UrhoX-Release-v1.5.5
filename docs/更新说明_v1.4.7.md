# 宇宙银河机甲 UrhoX 版 v1.4.7：修复攻击特效变形

只改 `scripts/jsrt/Renderer.lua`（和版本号），战斗逻辑、界面与 v1.4.6 相同。

## 问题（v1.4.6 引入）
v1.4.6 给激光、弹道、射线也加了光晕：光晕是把同一个模型整体放大 2.2 倍、再斜转 45 度。这些模型是细长的，放大后比本体长一倍多，斜转后和本体交叉：
- 玩家射线枪的子弹变成青色“十”字 / 飞机形；
- 狙击光束（由一串细长段组成）变成一条很宽的粉色斜纹带；
- 经验宝石也带上了光晕，变成一圈圈六边形。

## 修复
- 光晕只保留给方块状的小特效：白芯（fx_white）、火花（fx_spark）；激光、弹道、射线、经验宝石不再加光晕。
- 光晕放大 2.2 -> 1.8 倍，亮度 0.2 -> 0.18，每帧上限 110 -> 90。
- v1.4.6 的“叠加混合”本体保留：激光、弹道、射线仍是发光叠加效果，只是去掉了变形的外圈。

## 测试
渲染后端无头测试（第 3 章）：光晕只出现在白芯 / 火花上，叠加本体正常，无报错。
