# xpile-lite：网页版 JS -> UrhoX Lua 转换器

用途：网页版改了玩法（cosmic_data.js / cosmic_icons.js / cosmic_run.js）后，自动生成 UrhoX 版的 `scripts/jsrt/CosmicData.lua` 和 `CosmicRun.lua`。界面层（Hub.lua、GameUI.lua 等）是手写的 NanoVG，不经过转换。

```
node --expose-internals transpile.js cosmic_data.js cosmic_icons.js -o ../../scripts/jsrt/CosmicData.lua
node --expose-internals transpile.js cosmic_run.js -o ../../scripts/jsrt/CosmicRun.lua
```

- 需要 Node 16 以上。`--expose-internals` 让它使用 Node 自带的 JS 解析器 acorn；如果装了 acorn（`npm i acorn`），可以去掉这个参数。
- 只支持网页版现在用到的 ES5 写法（var / function / 对象 / 数组 / for / while / for-in / try）。遇到不支持的写法会直接报错并给出行号。
- 约定与运行库 `scripts/jsrt/JS.lua` 一致：第一个顶层 IIFE 是模块，里面的 var / function 变成 `S.xxx`（界面层通过 S 访问战斗状态，例如 `S.R`、`S:fireSub(true)`）。
- 验证方法：同一随机种子、同一操作序列，逐帧比较两份 Lua 的战斗状态（见更新说明）。
